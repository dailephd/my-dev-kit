===============================================================================
1. Behavior under test / participating layers
===============================================================================

Layers: classification producer (src/classification/*, new), manifest
registration (src/indexing/manifestTypes.ts, managedArtifacts.ts,
runSemanticAnalyzers.ts), compact-ref enrichment (src/graph/codeGraphTypes.ts,
src/symbol-index/types.ts + apply* functions), and regression protection for
v1.1-v1.4 (src/semantics/*, src/data-model/*, src/frontend/*,
src/frontend-reachability/*).

State variables under test: per-entry category assignment(s), editGuidance,
readiness, risks, evidence, uncertainty, warnings (classification-contract
section 3).

Events under test: index run with classification analyzer registered; index
run without it; re-run on unchanged source; re-run on changed source.

Derived values under test: editGuidance and readiness/risk as functions of
category + evidence + uncertainty (PSE-021, PSE-022, PSE-030-032).

  behavior-model explicitly defers them pending Batch 2 evidence (TST-020).

  performance on large projects is not addressed by this behavior model and
  would need its own test strategy addendum if it becomes a concern (v1.8
  scalability work is an explicit non-goal for this version line).
