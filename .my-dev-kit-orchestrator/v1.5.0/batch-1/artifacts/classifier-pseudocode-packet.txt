PSE-001: (BEH-010, BEH-013, TRN-001)
  function runClassificationAnalyzer(indexDir, projectRoot):
    manifest = loadManifest(indexDir)                       # existing loader, reused
    symbolIndex = loadSymbolIndex(indexDir)                  # existing loader, reused
    codeGraph = loadCodeGraph(indexDir)                      # existing loader, reused
    dataModel = loadOptionalArtifact(indexDir, 'data-model')          # may be absent
    frontendSemantic = loadOptionalArtifact(indexDir, 'frontend-semantic') # may be absent
    frontendReachability = loadOptionalArtifact(indexDir, 'frontend-reachability') # may be absent

    fileEntries = []
    for each file in symbolIndex.files (STABLE ORDER: as listed in symbolIndex, BEH-071):
      fileEntries.append(classifyFile(file, projectRoot, manifest))

    symbolEntries = []
    for each file in symbolIndex.files (same stable order):
      for each symbol in file.symbols (STABLE ORDER: declaration order, BEH-071):
        evidence = gatherSymbolEvidence(file, symbol, codeGraph, dataModel, frontendSemantic, frontendReachability)
        symbolEntries.append(classifySymbol(file, symbol, evidence))

    allEntries = fileEntries + symbolEntries               # deterministic concatenation order
    validateEntries(allEntries)                             # INV-001, INV-002, INV-003 checks

    writeClassificationArtifact(indexDir, allEntries)        # emits classification.json
    codeGraph2 = embedCompactRefs_CodeGraph(codeGraph, allEntries)
    symbolIndex2 = embedCompactRefs_SymbolIndex(symbolIndex, allEntries)
    writeCodeGraph(indexDir, codeGraph2)
    writeSymbolIndex(indexDir, symbolIndex2)

    manifest2 = registerClassificationAnalyzer(manifest, allEntries, status='complete')
    writeManifest(indexDir, manifest2)
    return { entryCount: allEntries.length, warnings: collectWarnings(allEntries) }

  function loadOptionalArtifact(indexDir, name):

    return null   # callers must treat null as "no evidence from this source", never throw

PSE-010: (BEH-021, category: generated-file)
  function classifyFile(file, projectRoot, manifest):
    candidates = []
    if matchesGeneratedFilePattern(file.path):
      # e.g. filename suffix convention, header comment convention, path under
      # a known generated-output directory referenced by manifest artifacts
      candidates.append(role='generated-file', confidence='certain' if strongPatternMatch else 'likely',
                         evidence=[ { kind:'filename-pattern', staticPattern: matchedPattern } ])

    if matchesConfigurationFilePattern(file.path):
      # e.g. known config filenames/extensions (*.config.*, *rc, package.json-like),
      # directory convention (root-level dotfiles)
      candidates.append(role='configuration-file', confidence='certain' if exactKnownName else 'likely', ...)

    if matchesCommandHandlerPattern(file.path):
      # directory convention: under src/commands/ AND exports a register*Command
      # style symbol (cross-check against symbol classification results is NOT
      # required here; file-level pattern match on path + naming convention is
      # sufficient per conservative rule - if ambiguous, defer to 'possible')
      candidates.append(role='command-handler', ...)

    if matchesAnalyzerPattern(file.path):
      # directory convention: under src/semantics/, src/data-model/, src/frontend/,
      # src/frontend-reachability/, filename contains 'Analyzer' or 'build*'
      candidates.append(role='analyzer', ...)

    if matchesValidatorPattern(file.path):
      candidates.append(role='validator', ...)

    if matchesTestFilePattern(file.path):
      # existing tests/ directory convention, *.spec.ts naming
      candidates.append(role='test-fixture', confidence='certain', ...)

    if matchesDocsPattern(file.path):
      if isUnderPlanningArtifactDirectory(file.path):     # e.g. .my-dev-kit-orchestrator/, historical .my-dev-kit-v1x-planning/
        candidates.append(role='internal-planning-docs', ...)
      else if isUnderDocsOrIsReadme(file.path):
        candidates.append(role='public-docs', ...)

    if candidates.isEmpty():
      return buildFileEntry(file, classifications=[], editGuidance='uncertain',
                              readiness='needs-more-context', uncertainty='unknown',
                              reason='no static file-level pattern matched')
                              # NOTE: this is still a *returned* entry with 0 classifications,
                              # distinct from omitting the entry entirely (behavior-model
                              # "Empty states" - only barrel/re-export files with literally
                              # nothing to say produce zero classification entries; a file
                              # that was checked and matched nothing still gets an entry
                              # documenting that absence, per INV-004/graceful-degradation intent)

    resolved = resolveCandidateConflicts(candidates)   # see PSE-040
    editGuidance = deriveFileEditGuidance(resolved)    # see PSE-020/PSE-021
    readiness, risks = deriveReadinessAndRisk(resolved, file)  # see PSE-030
    return buildFileEntry(file, resolved, editGuidance, readiness, risks, ...)

PSE-020: (BEH-020) reuse-by-name for existing SemanticRoleName overlap
  function classifySymbol(file, symbol, evidence):
    existingRole = lookupExistingSemanticRole(symbol)   # from symbol.semanticRoles, v1.1/v1.2 output
    candidates = []

    if existingRole is not null and existingRole.role in SHARED_CATEGORY_NAMES:
      # canonical-type, database-model, artifact-type, projection-type,
      # view-model, ui-only-state, persistence-adapter, route-handler,
      # client-component, server-component, test-fixture
      candidates.append(role=existingRole.role, confidence=mapSemanticConfidenceToUncertaintyTier(existingRole.confidence),
                         evidence=[ { kind:'existing-semantic-role', relatedRole: existingRole.role,
                                      artifactSource: existingRole.artifactRefs[0] if present } ])
      # BEH-020: spelling reused verbatim from existingRole.role, never renamed

    if evidence.frontendReachabilityFact is not null:
      # route-handler / client-component / server-component corroboration or
      # sole source when no v1.1/v1.2 role exists
      candidates.append(role=inferRoleFromReachabilityFact(evidence.frontendReachabilityFact),
                         evidence=[ { kind:'frontend-reachability-fact', ... } ])

    if evidence.dataModelCrossRef is not null and existingRole is null:
      # e.g. symbol appears as a canonical entity in data-model.json but v1.1
      # analyzer did not tag it (defensive fallback path, expected to be rare)
      candidates.append(role='database-model' or 'canonical-type' per dataModelCrossRef.kind,
                         evidence=[ { kind:'artifact-cross-reference', artifactSource: ... } ])

    if candidates.isEmpty():
      return buildSymbolEntry(file, symbol, classifications=[], editGuidance='uncertain',
                                readiness='needs-more-context', uncertainty='unknown',
                                reason='no existing semantic role and no static evidence found')

    resolved = resolveCandidateConflicts(candidates)
    editGuidance = deriveSymbolEditGuidance(resolved)
    readiness, risks = deriveReadinessAndRisk(resolved, file, symbol)
    return buildSymbolEntry(file, symbol, resolved, editGuidance, readiness, risks, ...)

PSE-021: (BEH-031, INV-003) deterministic edit-guidance pairing
  function deriveFileEditGuidance(resolved):
    if 'generated-file' in resolved.roles: return 'generated-do-not-edit'   # always, no exceptions
    if 'configuration-file' in resolved.roles: return 'inspect-before-edit'
    if 'internal-planning-docs' in resolved.roles: return 'read-only-reference'
    if 'public-docs' in resolved.roles: return 'docs-only'
    if 'test-fixture' in resolved.roles: return 'test-only'
    if resolved.overallUncertainty == 'unknown': return 'uncertain'          # INV-002
    if resolved.overallUncertainty in ('possible',): return 'inspect-before-edit'
    return deriveByRoleDefault(resolved.roles)   # command-handler/analyzer/validator -> safe-primary-edit-target
                                                   # (these are typically the *correct* place to edit
                                                   # my-dev-kit's own behavior, unlike database-model)

PSE-022: (BEH-032)
  function deriveSymbolEditGuidance(resolved):
    if resolved.overallUncertainty == 'unknown': return 'uncertain'  # INV-002
    if 'database-model' in resolved.roles or 'persistence-adapter' in resolved.roles:
      return 'avoid-primary-edit-target' if resolved.overallUncertainty == 'certain' else 'inspect-before-edit'
    if 'view-model' in resolved.roles or 'projection-type' in resolved.roles:
      return 'safe-primary-edit-target' if resolved.overallUncertainty in ('certain','likely') else 'inspect-before-edit'
    return 'inspect-before-edit'   # conservative default for remaining categories not yet mapped in Batch 1

  function createEvidence(kind, source, staticPattern=null, sourceLocation=null,
                            artifactSource=null, relatedRole=null, reason, uncertaintyReason=null):

PSE-031:
  function mergeEvidence(evidenceListA, evidenceListB):
    # deterministic merge: concatenate then de-duplicate by (kind, source, staticPattern, sourceLocation)
    # equality tuple, preserving first-seen order (BEH-071 determinism)
    return dedupeStable(evidenceListA + evidenceListB, keyFn=evidenceKey)

PSE-032: (BEH-060, BEH-061, INV-001, INV-002)
  function assignUncertainty(candidates, evidence):
    if evidence.isEmpty():
      return 'unknown'                                    # never 'certain' with no evidence, INV-001
    if candidates.length > 1 and evidenceStrengthsAreComparable(candidates):
      return 'possible'                                    # BEH-060, never rounded up to certain/likely
    if requiresRuntimeProof(candidates):
      return 'unknown'                                     # BEH-061
    if hasStrongUnambiguousEvidence(evidence):
      return 'certain'
    if hasSingleStaticPatternMatch(evidence):
      return 'likely'
    return 'possible'

PSE-033: (evidence -> warnings, deterministic)
  function addWarning(entry, kind, message):
    assert kind in ClassificationWarningKindValues
    if kind in ('possible-tier-warnings-required', 'unknown-tier-warnings-required'):  # conceptual gate, see below
      assert message is not empty
    entry.warnings.append({ kind, message })
    return entry

  function avoidOverclaiming(entry):
    if entry.uncertainty in ('possible', 'unknown') and entry.warnings.isEmpty():
      raise DesignViolation('possible/unknown-tier entry must carry >=1 warning explaining the limitation')
    return entry

PSE-040: (BEH-060)
  function resolveCandidateConflicts(candidates):
    if candidates.length == 1: return { roles: [candidates[0].role], overallUncertainty: candidates[0].confidence }
    grouped = groupByEvidenceStrength(candidates)
    if grouped.strongest.length == 1:
      return { roles: [grouped.strongest[0].role], overallUncertainty: grouped.strongest[0].confidence }
    # multiple candidates tie at the strongest evidence tier -> ambiguous
    return { roles: grouped.strongest.map(c => c.role), overallUncertainty: 'possible',
             warningsToAdd: [{ kind: 'conflicting-category',
                                message: 'multiple statically plausible categories: ' + grouped.strongest.map(c=>c.role).join(', ') }] }

7. Acceptance criteria (for Batch 2+ implementation)
===============================================================================

AC-001: Running the index command with the classification analyzer registered
produces classification.json with schemaVersion '1.0.0' and a manifest.json
analyzer entry with id 'classification' and status reflecting success/failure
accurately.

AC-002: Every entry in classification.json satisfies INV-001, INV-002, INV-003
(validated by validateEntries in PSE-001) before the artifact is written; a
violation is a build-time assertion failure in the analyzer, not a silently
written malformed artifact.

AC-003: classificationRoles/classificationRefs appear on CodeGraphNode entries
of kind 'symbol' and on GraphSymbolRecord entries exactly where a
corresponding classification.json entry exists, using the same map-by-id
pattern as applySemanticRolesToCodeGraph/applySemanticRolesToSymbolIndex
(byte-for-byte structural mirror, per architecture-context section 11).

AC-004: Existing semanticRoles/artifactRefs values are provably unchanged
(same before/after diff on those two fields specifically) after the
classification analyzer runs, for a fixture project that already has v1.1/v1.2
semantic roles.

AC-005: Running index twice on an unchanged source tree produces byte-identical
classification.json (BEH-071/AC determinism check).

AC-006: Removing classification.json and re-running index without the
classification analyzer registered leaves search/lookup/slice/source output
unchanged from a pre-v1.5 baseline (INV-004 graceful degradation).

AC-007: A file with zero static evidence still receives a returned entry
documenting the absence (uncertainty='unknown', editGuidance='uncertain'),
distinguishable from a file that was never evaluated - per the "empty vs.
absent" distinction in PSE-010.
