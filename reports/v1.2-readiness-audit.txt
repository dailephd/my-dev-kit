CORRECTIVE CHANGES MADE
-----------------------

1. examples/basic-react-tsx missing from package.json "files" array
   File: package.json
   Fix: Added "examples/basic-react-tsx/src" and "examples/basic-react-tsx/README.md"
   Impact: Without this fix, the basic-react-tsx example would not appear in
   the published npm package, making the bundled example inaccessible to
   consumers who install from npm.

2. Package version not bumped from 1.1.0 to 1.2.0
   Files: package.json, package-lock.json, src/version.ts
   Fix: Updated version to 1.2.0 in all three files.
   Impact: Without this fix, the published package would report version 1.1.0
   and the CLI --version flag would output "1.1.0" for a 1.2 release.

3. CHANGELOG.md had no 1.2.0 entry and an unfilled YYYY-MM-DD placeholder
   File: CHANGELOG.md
   Fix: Added v1.2.0 entry dated 2026-06-18 with full feature list;
   fixed v1.1.0 placeholder date to 2026-05-01.
   Impact: Release notes were absent for v1.2.0.

Additional update: docs/PROJECT_OVERVIEW.md updated from "Version 1.1.0" to
"Version 1.2.0" and the current scope section expanded to cover v1.2 features.
